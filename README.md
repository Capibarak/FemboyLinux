# FemboyLinux
my first arch based distro

# How to build
you need to have archlinux a vm will work clone the repo by doing "git clone https://github.com/Capibarak/FemboyLinux.git" then do "cd FemboyLinux" then just run building.sh for gnome version or builds way.sh for sway version if it doesn't run do chmod +x building.sh or chmod +x buildsway.sh and retry running building.sh or buildsway.sh
